# DEEPCORE — Noyau Profond

Roguelike au tour par tour (inspiré de Cogmind et Brogue) : une foreuse se pose sur une planète inconnue, l'explore
et fore la roche à la recherche de sites et de cristaux, face à une faune hostile.

- **Jouer** : l'artefact claude.ai https://claude.ai/artifact/NL3Dn842a32JiGimprg8cm
- **Assembler le jeu** : `python3 build.py` → `dist/noyau-profond.html` (un seul fichier, s'ouvre dans un navigateur)
- **Conception** : [docs/conception.md](docs/conception.md)
- **Sources** : `src/` (page, style, scripts découpés par thème)
